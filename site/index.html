gopherstack

Lightweight, in-memory AWS cloud stack in a single Go binary. Emulates 150+ AWS service APIs locally in milliseconds with real cross-service integration (DynamoDB Streams to Lambda, SNS to SQS fan-out, EventBridge Scheduler & Pipes), a built-in web dashboard, named state snapshots, and a native MCP server for AI assistants.

Quick start 
docker run -p 8000:8000 ghcr.io/blackbirdworks/gopherstack:latest

semaphore

Self-hosted, cloud-native feature flag relay proxy and embeddable Go evaluation engine built on OpenFeature and the OFREP protocol. Wire-compatible with GO Feature Flag providers with a vendored rules engine, flexible retrievers and exporters, and full hosted documentation.

Quick start 
./semaphore --config semaphore-proxy.yaml

Built for Real Systems

Every project focuses on clean ergonomics, deterministic behavior, and low-overhead deployment.

01

Single-Binary Efficiency

Whether emulating cloud APIs in memory or managing log storage quotas, tools ship as compact, self-contained binaries with zero runtime bloat.

02

Open Protocols & Wire Compatibility

Built around established standards—AWS SDK protocols, OpenFeature OFREP, OpenTelemetry, Cobertura XML, and Huma's router-agnostic interfaces—so existing tooling works out of the box.

03

Self-Hosted Pragmatism

Designed for developers and platform engineers alike: minimal configuration, clear diagnostics, and reliable operation on local workstations, CI pipelines, or containerized deployments.
