gopowerwall

  • Original
  • Go
  • v0.2.9

Idiomatic Go port of pypowerwall for Tesla Energy Gateways (Powerwall 2, Powerwall+, and Powerwall 3). Exposes both a typed Go client and a drop-in HTTP proxy compatible with existing Home Assistant, Telegraf, and Grafana setups.

GitHub Repo for gopowerwall Releases for gopowerwall

Install

Go Binaries 
go install github.com/blackbirdworks/gopowerwall/cmd/gopowerwall@latest
go install github.com/blackbirdworks/gopowerwall/cmd/proxy@latest

Connection Modes

Supported Powerwall transport backends
Flag Transport Credentials / Notes
--local Gateway HTTPS REST API --host + --password (last 5 chars of gateway password).
--tedapi Protobuf over gateway AP --gw_pwd (gateway WiFi password), defaults to 192.168.91.1.
--v1r RSA-signed LAN TEDAPI Powerwall 3 wired LAN using --gw_pwd + --rsa_key_path.
--cloud Tesla Owner API Reads .pypowerwall.auth / TESLA_REFRESH_TOKEN with auto token refresh.
--fleetapi Official Tesla Fleet API Reads .pypowerwall.fleetapi with automatic OAuth2 token refresh.

CLI & Proxy Usage

Shell 
gopowerwall get --local --host 192.168.91.1 --password abcde --format json
gopowerwall set --local --host 192.168.91.1 --password abcde --mode self_consumption --reserve 20
gopowerwall scan 192.168.1.0/24 --json
gopowerwall proxy --local --host 192.168.91.1 --password abcde --port 8675
